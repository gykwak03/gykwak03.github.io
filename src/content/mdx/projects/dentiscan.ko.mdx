**DentiScan**은 구강 사진 한 장에서 충치와 치아 마모 의심 부위를 선별하는 2단계
프로토타입입니다. 탐지 모델이 작은 후보 영역을 먼저 찾고, 분류 모델이 잘라낸 각 후보
이미지를 다시
검토해 정상으로 예측된 영역을 제외합니다. 불균일한 조명, 작은 병변 경계, 병변과 유사하게
보이는 정상 치아 표면을 함께 고려하기 위해 탐지 후 검증 구조를 채택했습니다.

환자 295명의 고해상도 구강 사진 약 1,200장으로 구성된 AlphaDent를 사용했습니다.
픽셀 단위 마스크를 탐지 라벨로 변환하고, 네 범주의 분류 이미지 14,497개를 구축했습니다.
모델 개발 과정에서는 구성 요소별 성능 비교 실험을 수행하고, 탐지 모델 RF-DETR과 D-FINE,
분류 모델 Swin Transformer와 RegNet을 비교했습니다. 마모 객체가 충치보다 1.76배 많아
소수 클래스인 충치 객체를 25% 늘리는 Copy-Paste 증강을 적용했습니다.

증강 전 데이터에서 탐지 정밀도는 **RF-DETR 81.28%, D-FINE 63.78%**였습니다.
최종 파이프라인에서는 RF-DETR의 탐지 결과를 Swin Transformer로 다시 검토하고,
정상으로 분류된 후보를 제외해 오탐을 줄이도록 설계했습니다. 탐지 단독과 비교했을 때
2단계 검증에서 놓친 실제 병변도 늘었습니다. 다른 출처의 데이터셋에서는 성능이
낮아져, 촬영 환경과 데이터 출처에 따른 일반화 한계를 확인했습니다.

추론 파이프라인은 Streamlit 애플리케이션에 통합해 AWS EC2에 배포했습니다. 결과
화면에는 후보 영역, 신뢰도, 병변 수, 후보 영역 이미지를 함께 표시하며, 분석 결과가 의료
진단이 아니라 치과 전문의 확인이 필요한 스크리닝 참고 정보임을 명시했습니다.
