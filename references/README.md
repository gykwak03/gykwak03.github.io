# Reference assets

This directory contains source material that is useful when editing the
portfolio but should not be served as a public website asset.

- `source-documents/`: original slide decks and superseded résumé files
- `source-images/`: screenshots that are currently not displayed
- `source-logos/`: original or replaced logo files
- `legacy-3d/`: the retired Blender/Three.js hero-object source
- `archive/`: recoverable local cleanup snapshots; ignored by Git

Files displayed by the website belong in `public/images/` or `public/logos/`
and use lowercase kebab-case names.
